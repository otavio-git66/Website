# Sabor da Casa

Site institucional responsivo para um restaurante brasileiro, desenvolvido com HTML e CSS puro. A página apresenta a identidade visual do restaurante, uma chamada principal, sua história, pratos em destaque, informações de contato e uma área de reserva de mesa.

## Visão geral

O **Sabor da Casa** foi pensado para transmitir acolhimento, simplicidade e qualidade. A interface combina tons terrosos, verde profundo e tipografia editorial para criar uma experiência elegante sem perder a proximidade de um restaurante de bairro.

Entre os conteúdos disponíveis estão:

- Logo e navegação para as principais áreas da página;
- Seção de apresentação com a proposta do restaurante;
- Menu com fotos, descrições e preços de pratos;
- Horário de funcionamento destacado;
- Telefone, e-mail e endereço para contato;
- Botões de reserva e navegação por âncoras;
- Layout adaptado para computadores, tablets e celulares.

## Estrutura

```text
.
├── index.html   # Estrutura e conteúdo da página
├── style.css    # Identidade visual, layout e responsividade
└── README.md    # Documentação do projeto
```

## Como visualizar

1. Baixe ou clone este projeto.
2. Abra o arquivo `index.html` em qualquer navegador moderno.

Não é necessário instalar dependências ou executar um servidor para visualizar a versão atual. As imagens dos pratos e as fontes tipográficas são carregadas de serviços externos, portanto uma conexão com a internet melhora a experiência completa.

## Personalização

Os dados de contato, preços, endereço e textos ficam diretamente no `index.html`. As cores, espaçamentos, tipografia e regras de adaptação para telas menores podem ser ajustados no início do `style.css`, nas variáveis definidas em `:root`.

## Tecnologias

- HTML5 semântico;
- CSS3 com Grid, Flexbox e media queries;
- Google Fonts;
- Imagens responsivas hospedadas no Unsplash.
